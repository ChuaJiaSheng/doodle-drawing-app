# Doodle Drawing App

A drawing application with brush, pen, eraser, text, emojis and image loading/saving.

**Technology:** C# and Windows Forms.

## Run or inspect

On Windows, open `Doodle_222257U.sln` in Visual Studio with .NET Framework 4.7.2 support. Build and run the solution. Source and image resources are retained; machine-specific alternate source copies and compiled outputs are left in the full backup.
